## 🚀 Description

Ce projet est un **framework de génération de patterns de mots de passe en streaming**, conçu pour :

- analyse de robustesse des mots de passe
- simulation de comportements utilisateurs
- recherche en cybersécurité défensive
- tests en laboratoire sécurisé
